FAQ

Frequently Asked Questions

Why does Android show a warning when installing the APK?

Android displays a standard "File might be harmful" or "Unknown app" warning whenever an APK is installed directly from the web rather than the Google Play Store. VEXLORA EchoBand is 100% open-source, safe, and contains zero trackers or ads. You can safely tap Install anyway.

Can I use my own Gemini API Key?

Yes! In the app's Settings screen, you can paste your own Google Gemini API key directly to unlock unlimited high-speed requests, or you can use our pre-configured cloud gateway without entering any keys.

Does it only work with Sony WH-CH510 headphones?

While EchoBand is specifically tested and optimized for the Sony WH-CH510 button hooks and Bluetooth SCO profile, it works seamlessly with any Bluetooth earbuds, wired headphones, or directly through your phone's built-in speaker and microphone.

How does phone hardware control work?

EchoBand parses speech intents locally. Phrases like "torch on", "volume 70%", or "timer for 5 minutes" trigger native Android system services (CameraManager, AudioManager, and AlarmClock) with zero cloud latency.
